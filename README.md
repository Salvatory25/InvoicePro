# InvoicePro — Multi-Tenant Invoicing, Quotations & Receivables SaaS

InvoicePro is a production-oriented, multi-tenant invoicing, quotation, client-work, and receivables management SaaS built for freelancers, consultants, agencies, contractors, and SMBs in **Tanzania** and across **East Africa** (`TZS`, `KES`, `UGX`, `RWF`, `USD`, `EUR`, `GBP`) with full **English (`en`)** and **Kiswahili (`sw`)** support.

---

## 1. Architecture & Technology Stack

- **Frontend:** React 19, TypeScript (Strict mode), Vite 6, Tailwind CSS 4, React Router 7, Lucide Icons, Zod.
- **Financial Arithmetic Engine (`src/lib/money.ts`):** Exact integer minor-unit (`BigInt`) decimal arithmetic with deterministic half-up rounding. IEEE-754 floating-point math is **never** used as the source of truth for financial totals, taxes, discounts, or balances.
- **Database & Backend (`supabase/migrations/20261028000001_invoicepro_schema.sql` & `src/services/database.ts`):**
  - Normalized PostgreSQL schema (29 tables) with foreign keys, check constraints, and Row Level Security (RLS).
  - Atomic sequential document numbering (`INV-2026-0001`, `QUO-2026-0001`, `PRO-2026-0001`, `CN-2026-0001`, `RCT-2026-0001`) scoped per business.
  - Database trigger (`trg_issued_invoice_immutability`) and service-layer enforcement preventing silent rewriting of issued financial documents.
  - Supabase Edge Functions (`supabase/functions/ai-assistant` and `supabase/functions/send-notification`) for server-side privileged operations.
  - Dual-adapter runtime: Connects to live Supabase PostgreSQL when `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` are configured with `VITE_DB_MODE=supabase`, or runs against the embedded transactional relational engine (`VITE_DB_MODE=local`) for immediate local inspection and automated testing.

## 2. Quick Setup & Local Development

```bash
# 1. Install dependencies
npm install

# 2. Copy the environment variable template
cp .env.example .env.local

# 3. Run type-checking

# 4. Run the automated test suite (18+ critical workflows & negative security tests)

# 5. Start the development server
npm run dev

# 6. Build for production
npm run build
```

## 3. Regulatory & Fiscal Compliance Notice (Tanzania TRA EFD/VFD)

Ordinary commercial invoices, proforma invoices, credit notes, and payment receipts generated by InvoicePro are **commercial billing documents** and are **not automatically TRA EFD or VFD fiscal receipts**. Every generated document and PDF carries an explicit bilingual non-fiscal notice. Fiscal-document issuance is isolated behind the `tra_vfd_module_enabled` integration flag and must only be enabled after an approved TRA VFD provider integration and compliance review are completed.
